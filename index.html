Todas as funcionalidades num só lugar

O Saborify foi pensado como um laboratório de receitas para o teu dia a dia, mas também como um projeto académico completo.

  • ✅ Catálogo de receitas com imagens, tempo e tipo de prato.
  • ✅ Filtros dinâmicos por categoria, dificuldade e duração.
  • ✅ Sistema de favoritos baseado em JSON de receitas.
  • ✅ Login com utilizador comum e conta de administrador.
  • ✅ Página de perfil com informações do utilizador e receitas favoritas.

Modo administrador

Ao entrar como Admin, tens acesso a funcionalidades extra para gestão do catálogo de receitas, ideais para demonstrar o lado de backoffice do projeto.

Todas estas interações são feitas apenas no front-end, usando arrays de objetos em JavaScript para simular dados guardados.
